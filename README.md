# java-calculator-precourse

## 1. 입력 처리 (InputView)

- [x]  사용자로부터 덧셈할 문자열을 입력받는다.

## 2. 구분자 추출 (DelimiterExtractor)

- [x]  기본 구분자를 반환한다.
- [x]  커스텀 구분자
    - [x]  커스텀 구분자를 추출한다.
    - [x]  커스텀 구분자 접두사를 제거하고 숫자 부분만 반환한다.

## 3. 숫자 파싱 (NumberParser)

- [x]  구분자를 기준으로 문자열을 분리한다.
- [x]  분리된 각 문자를 숫자로 변환한다.

## 4. 계산 (Calculator)

- [x]  문자를 더하기 계산해서 반환한다.

## 5. 출력 처리 (OutputView)

- [ ]  계산 결과를 출력한다.
- [ ]  에러 메시지를 출력한다.

## 6. 전체 흐름 제어 (CalculatorController)

- [x]  사용자 입력을 받는다.
- [x]  계산을 수행한다.
- [ ]  결과를 출력한다.

## 7. 예외 처리
- [ ]  모든 예외 메시지는 `[ERROR]`로 시작한다.
- [ ]  잘못된 입력 시 `IllegalArgumentException`을 발생시킨다.
- [ ]  예외 발생 시 애플리케이션이 종료된다.
